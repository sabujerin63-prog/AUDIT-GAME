# 🕵️ AUDIT DETECTIVE: THE SAMPLING QUEST
### *M.Com Semester 1 &bull; Module 4 Interactive Game (Mobile & Desktop)*

---

## 🎮 How to Play
1. **Quick Launch**: Open [`index.html`](./index.html) or run [`launch_game.bat`](./launch_game.bat).
2. **Mobile Support**: Fully optimized for mobile phone browsers (Chrome, Safari, Edge, Firefox):
   - Responsive UI that scales to any screen width.
   - On-screen touch D-Pad (`▲`, `▼`, `◀`, `▶`).
   - Ergonomic `🔍 ACTION` and `⚡ RUN` thumb buttons.
   - Touch-friendly, scrollable answer modals.
3. **Desktop Controls**:
   - `Arrow Keys` or `W`, `A`, `S`, `D` to move.
   - `Shift` to sprint.
   - `E` or `Spacebar` to inspect stations.
4. **Startup Name Customization**:
   - The game **starts directly with the Profile Setup screen**.
   - Type your name, pick presets, select your auditor suit color, and click **"START AUDIT ADVENTURE"** to begin!

## 🔀 Shuffled Options & Lives System
* **Randomized Options**: Correct answers are dynamically mixed across **A, B, C, and D** every attempt.
* **3 Lives System**:
  - 1st mistake: Continue with **2 lives**.
  - 2nd mistake: Continue with **1 life**.
  - 3rd mistake: All 3 lives lost -> **Game Over with Restart option**.
* **End Screen**: Congratulations banner, score summary, lives preserved, and a **`🔄 Restart Game`** button.
